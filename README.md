# 🎵 Vinylify Studio

A personal retro vinyl turntable and playlist manager that runs entirely in your browser.

## ✨ Features

- 🎚️ **Playlist Management** — Create, rename, delete playlists
- 📁 **MP3 Upload** — Store MP3 files locally in IndexedDB
- ▶️ **YouTube Support** — Play YouTube videos via IFrame API
- 🎨 **Vinyl Animation** — Realistic spinning vinyl with tonearm movement
- 🎛️ **Audio Controls** — Pitch, RPM, EQ, Lo-Fi filter, Vinyl crackle
- 📝 **Lyrics** — Search LRCLIB for lyrics, upload .lrc files, real-time sync
- ⌨️ **Keyboard Shortcuts** — Space, N, P, L, Arrow keys
- ⏰ **Sleep Timer** — Auto-stop after selected time
- 💾 **Export/Import** — Backup your playlists as JSON
- 🔒 **100% Private** — All data stays in your browser

## 🚀 Live Demo

[vinylify-studio.vercel.app](https://vinylify-studio.vercel.app)

## 🛠️ Tech Stack

- HTML5 + CSS3 + JavaScript (Vanilla)
- Tailwind CSS
- IndexedDB (local storage)
- YouTube IFrame API
- LRCLIB API (lyrics)
- Web Audio API
